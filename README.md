# Truth 6.0 - Master Pro 全球資產配置決策儀表板

## 📌 專案簡介
Truth 6.0 是一個基於 Streamlit 開發的高階全球資產配置系統。它結合了 **生命週期投資 (Life-cycle Investing)**、**動態風險控管 (Dynamic Risk Management)** 與 **總體經濟分析 (Macro Analysis)**，旨在為使用者提供隨年齡與市場環境動態調整的投資組合建議。

本系統的核心邏輯在於：在承平時期實施嚴格的「守成模式」以保護資本；在市場恐慌、大回檔時切換為「掠食者模式」進行抄底。

---

## 🚀 核心功能與邏輯架構

### 1. 個人化配置中樞 (Glide Path)
系統根據使用者目前的年齡與預計退休年齡，計算「距離退休年數 (`ytr`)」，並對應不同的股票中樞比例 (`pivot_stock`)：
- **距退休 > 25 年**: 85%
- **距退休 20-25 年**: 80%
- **距退休 15-20 年**: 70%
- **距退休 10-15 年**: 60%
- **距退休 5-10 年**: 55%
- **距退休 0-5 年**: 45%
- **已退休 (`ytr <= 0`)**: 40%

### 2. 市場模式判定 (Market Regimes)
系統透過 `VT` (全球股票) 的技術指標與 VIX 波動率將市場分為三種狀態：
- **🟢 Normal (正常)**: 大盤站上 200MA 且市場寬度健康。
- **🟡 Caution (警戒)**: 大盤跌破 200MA、多個子市場轉弱或偵測到 FTD (反彈確認日) 失效。
- **🔴 Crisis (危機)**: 大盤回檔超過 20% 或 VIX 飆升至 30 以上。

### 3. 動態偏移與年齡壓縮 (Tactical Tilt)
在警戒模式下，系統會進行減碼，且減碼力道隨年齡增加而加劇：
- **減碼公式**: `Regime Tilt = -5.0% * Age Compression`
- **Age Compression**: `max(0.2, (年齡 - 20) / 40)` (年長者對市場風險更敏感)。

### 4. 雙重防禦機制：守成 vs. 掠食者
- **🟢 守成模式 (Safe Cap)**: 
    - 觸發：回檔未達 20%。
    - 限制：股票上限不能超過 `min(100 - 年齡, 50 + ytr)`。多餘資金強制轉入現金避險。
- **🔴 掠食者模式 (Predator Mode)**:
    - 觸發：大盤回檔 $\ge 20\%$。
    - 行為：解除 `Safe Cap` 封印，股票上限釋放至 **80%** (需保留 10% 黃金)，並在危機模式下強制加碼 **+10%**。

### 5. 領先指標集成
- **FTD Guard**: 追蹤跟進日訊號，防止過早進場或太晚撤退。
- **PMI 趨勢**: 自動抓取並判定 PMI 的 Up/Down/Flat 趨勢，決定美林時鐘象限。
- **CNN Fear & Greed**: 整合 CNN 情緒指標作為心理層面的確認訊號。
- **Inflation Nowcast**: 對接克里夫蘭聯準會 Nowcast，即時判斷通膨驚喜與債券保護需求。

## 🛠 安裝與啟動

### 環境要求
- Python 3.9+
- Conda (建議)

### 安裝步驟
1. 複製專案到本地。
2. 安裝依賴套件：
   ```bash
   pip install -r requirements.txt
   ```

### 啟動應用程式
```bash
streamlit run truthasset.py
```

## 📊 資產配置辯論共識
- **核心股票**: 滾動調整 (VT / VTI / QQQ / 0050)。
- **避險黃金**: 預設 10%，在滯脹 (Stagflation) 階段會額外提升 5% 以對抗通膨。
- **防護債券**: 視通膨驚喜與利率趨勢自動開啟「債券保護機制 (Bond Protection)」，將債券部位暫時轉入現金。
- **生存現金**: 系統最終會檢核「現金 + 債券」是否足以支撐 10% 的最低生存金底線。
